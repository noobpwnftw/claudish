en_US → cd_AI AN INPUT METHOD FOR AI

If you can type there,
you can use AI there.

cd_AI is an input method for Linux, Windows, and macOS. Switch to it like any keyboard language, type a few plain words, and press Tab: they come back as the prose the internet now runs on, or in another tone.

English goes in. Em dashes come out.

Try it in your browser Download

For macOS (Apple silicon), Windows 11, and Linux.

RECORDED ON MACOS

From “ok” to corporate prose.

A terminal task, handed to Claude Code

Shift+Enter drafts a command; Tab puts it at the prompt and Enter runs it. For the task, Claude Code starts on a session with a note of the conversation, in the project folder.

01 / TWO MODES, ONE SHIFT

Compose, or continue—Shift switches.

Rewrite

Type a few words and press Tab: the rewrite appears in the panel. Tab again inserts it.

you typecan't make it tonight, sorry
cd_AIRegrettably, I must convey that I won't be able to make it tonight—my current bandwidth is fully allocated to high-priority deliverables, but I look forward to connecting when our schedules realign!
Tab

Ask

Type what you want and press Shift+Enter: drafts wait in the panel, ↑↓ picks one, and Tab takes it.

draft 1I genuinely appreciate you carving out time to connect with me; however, at this juncture, I am unable to make the proposed meeting time work.
Tab
draft 2I sincerely appreciate you extending this invitation to connect—it sounds like a truly valuable discussion! Regrettably, due to prior commitments that require my full focus, I won't be able to make the scheduled time.

03 / THE KEYS

Everything else is typing.

Shifttap to switch: continue or compose
Tabtake the model's text: the suggestion, a rewrite (shown first; Tab again puts it in), the highlighted draft
Shift+Enterin compose, send it as an instruction, a follow-up, or a reply
Enterin compose, keep it as it is
↑ ↓choose a draft or an answer; Tab takes it
F8with an instruction, also send this window
Escone step back: what you typed, then edit, then drop
Shift+Escbring back what Esc dropped, or the exchange you left
04 / MODELS

The caret is model-agnostic.

  • Backends. A Claude subscription through Claude Code, a ChatGPT subscription through Codex, Claude with an API key, or any OpenAI-compatible server.
  • Or local. setup --profile local downloads llama.cpp and Gemma 4 E4B (4.9 GB).
  • Context. Files, commands, and MCP servers, per app.
  • Tools and agents. An instruction may call your MCP tools, ask you a question, or hand the task to Claude Code or another agent.
05 / INSTALL

Download, open, choose a model.

  • macOS · cd_AI.pkg Apple silicon. Not signed by Apple, so macOS blocks it once: click Done (not Move to Trash), then System Settings → Privacy & Security → Open Anyway, twice. Then log out and back in.
  • Windows 11 · cd_AI-setup.exe Not signed, so SmartScreen asks: More info → Run anyway. Then restart, and pick Claudish with Win+Space.
  • curl -fsSL https://raw.githubusercontent.com/noobpwnftw/claudish/v0.2.0/scripts/install.sh | sh
    Linux (IBus). Then log out and back in, and add English → Claudish in your input sources.

Each ends in cd_AI's settings: add an Anthropic API key, pick Claude Code for a Claude subscription or Codex for a ChatGPT subscription, or give another model API. Pick a tone and use Try a rewrite; then type ok in an app, Tab to preview, Tab again to insert.

A development checkout, with a coding agent

For working on cd_AI: paste this into Claude Code (or any coding agent). Every install route is in docs/install.md.

PROMPT
Install Claudish (cd_AI), an input method that puts a language model at the caret, on this computer.

1. Check that Python 3.10 or newer and git are installed. If not, tell me how to install them and stop. On macOS, clone the repository (step 2), run `python3 platforms/macos/build.py` and `python3 platforms/macos/package.py` there, and open `dist/macos/cd_AI.pkg`. The installer opens cd_AI's settings; continue at step 5, then log out and back in.
2. Clone https://github.com/noobpwnftw/claudish into ~/claudish (or pull it if it is already there) and work in that folder. Use python3 on Linux and macOS, python on Windows.
3. Create a virtual environment there and install it with the Claude SDK: `python -m venv .venv`, then `.venv/bin/python -m pip install -e ".[claude]"` (`.venv\Scripts\python` on Windows). Use that venv's Python for every `python -m claudish` command below.
4. Run `python -m claudish setup --yes`. It writes a config, registers the input method (on Linux; on Windows the input method comes from cd_AI-setup.exe, see docs/install.md), and starts cd_AI at login.
5. Run `python -m claudish settings` if the installer has not opened it. Help me pick my existing model: Claude Code for a Claude subscription, Codex for a ChatGPT subscription, Claude with an API key, or another model API. If a subscription command is missing or not logged in, help install it and log in. Use Try a rewrite in Settings to check that my chosen model answers. Let me enter any key in Settings myself.
6. Run `python -m claudish doctor` and follow its fixes until every check passes, or explain what is left.
7. Finish by telling me how to start: on Linux, log out and back in and add "English → Claudish" in my input sources; on Windows, run cd_AI-setup.exe (docs/install.md), restart, and pick Claudish with Win+Space. Then the keys: cd_AI starts in compose, where Tab asks for a rewrite (Tab again puts it in), Shift+Enter sends my words as an instruction, Enter keeps them as typed, and Esc steps back; tapping Shift switches to continue, where keys go straight in.

Or by hand

git clone https://github.com/noobpwnftw/claudish
cd claudish
python3 -m venv .venv
.venv/bin/python -m pip install -e ".[claude]"
.venv/bin/python -m claudish setup
.venv/bin/python -m claudish settings

Settings opens in your browser: choose Claude Code, Codex, Claude with an API key, or another model API; pick a tone and try a rewrite. On macOS, the installer opens it. Details in docs/install.md.
