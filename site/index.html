If you can type there,
you can use AI there.

cd_AI is an input method for Linux, Windows, and macOS. Switch to it like any keyboard language, and what you type goes to a model you choose: a small local one by default, or your own API key. The answer arrives as a candidate at the caret.

English goes in. Em dashes come out.

01 / TWO MODES, ONE SHIFT

Continue, or compose—Shift switches.

Continue

What cd_AI starts in: you type as usual; pause, and the rest of the sentence waits after the caret.

you typeThanks for the review on
cd_AI…the parser change.Tab

Instruct

In compose, type what you want; Enter sends it; drafts wait in the panel, and Tab takes one. It can look things up first, and ask before it acts.

you typedecline the meeting politely
cd_AIthree drafts to choose fromTab

Rewrite

In compose, Tab shows ordinary English as unnecessarily polished prose; Tab again puts it in.

you typethis is important
cd_AIThis is of utmost significance.Tab
02 / FOR EVERYONE WHO WRITES

Help where you write, in your own words.

No new app and no copying into a chat window: the help comes to the box you are already typing in, and nothing happens until you press a key.

Fix it, keep it yours

With the fix tone, Tab corrects spelling and grammar and keeps your words: for dyslexia, a second language, or a hurried day.

you typepump 3 trippd agian, no injurys
cd_AIpump 3 tripped again, no injuriesTab

Say what you need

In compose, describe the message and press Enter; choose a draft, or press Esc for your own words back.

you typeflour 2 bags short, credit by tuesday
cd_AIWe were two bags short today. Could you credit them by Tuesday?Tab

Ask what it means

Ask about what is in front of you. The answer is shown to read, and goes into your text only if you say so.

you typewhat does this error mean
cd_AIIt can't find a piece it needs to build.Esc
  • Nothing goes anywhere by itself. It never sends, posts, or saves for you. Every suggestion waits for your key, and Esc brings back what you typed.
  • Fewer keystrokes. Tab finishes a sentence, and a few words become a whole reply: kind to tired hands and sore wrists.
  • Your tone. Claudish's own voice, polished and fond of em dashes, is the default. Choose fix, plain, or describe your own.
  • Your model, your key. cd_AI ships no model: it uses the one you point it at, a frontier model with your own key or one on your own computer. Password fields are never touched.
03 / THE KEYS

Everything else is typing.

People who type Chinese or Japanese already know this grammar: compose, see the candidates, choose, commit. Claudish extends it from what you meant to say to what you meant to do.

Shifttap to switch: continue or compose
Tabtake the model's text: the suggestion, a rewrite (shown first; Tab again puts it in), the highlighted draft
Enterin compose, send it as an instruction, a reply, or an answer; it never inserts the model's text
Shift+Enterin compose, keep it as it is
↑ ↓choose a draft (Tab inserts it) or an answer (Enter sends it)
F8with an instruction, also send this window
Escone step back: what you typed, then edit, then drop
Shift+Escbring back what Esc dropped, or the exchange you left
04 / BRING YOUR OWN INTELLIGENCE

The caret is model-agnostic.

  • Local by default. llama.cpp and a 491 MB model, downloaded and checksum-verified by setup. Nothing leaves your machine.
  • Or yours. Claude with your API key, any OpenAI-compatible server, or an agent CLI. Hosted backends are labelled.
  • Context. Files, commands, and MCP servers, per app: the PR diff in your editor, the ticket in your browser. Import the MCP servers you already use with Claude.
  • Tools and agents. An instruction may call your MCP tools, ask you a question, or hand the task to Claude Code or another agent. You approve every side effect.
  • Restraint. It runs only on what you type, looks at the screen only when you press F8, and never inserts anything you did not accept. Password fields bypass it.
05 / INSTALL

Let your agent do it.

Paste this into Claude Code (or any coding agent) on the computer where you want Claudish. It shows you the plan before it changes anything, and leaves sudo and administrator steps to you.

PROMPT
Install Claudish (cd_AI), an input method that puts a language model at the caret, on this computer.

1. Check that Python 3.10 or newer and git are installed. If not, tell me how to install them and stop.
2. Clone https://github.com/noobpwnftw/claudish into ~/claudish (or pull it if it is already there) and work in that folder. Use python3 on Linux and macOS, python on Windows.
3. Run `python -m claudish setup --dry-run`, show me the plan, and ask me before continuing.
4. Run `python -m claudish setup --yes`. It writes a config, registers the input method, and starts Claudish at login. It ships no model: it is set up for Claude with my own key. Install the extra with `pip install "claudish-ime[claude]"` and ask me to put my key in the ANTHROPIC_API_KEY environment variable myself; never ask me to paste it to you, and never write it into a file. (If I want a small local model instead, `--profile local` downloads one.)
5. If setup says a step needs me (sudo on Linux, an administrator PowerShell or the PIME installer on Windows, a build on macOS), show me the exact command and why. Do not run anything with sudo or as administrator yourself.
6. Run `python -m claudish doctor` and follow its fixes until every check passes, or explain what is left.
7. Finish by telling me to log out and back in, add "cd_AI — Claudish" in my input sources, and the keys: tapping Shift switches between continue and compose; Tab takes the model's text (a suggestion, a rewrite once shown, a draft); in compose, Enter sends my words as an instruction and Shift+Enter keeps them as they are; Esc steps back.

Make no mistakes.

Or by hand

git clone https://github.com/noobpwnftw/claudish
cd claudish
python3 -m claudish setup

Setup asks before each step and skips what is already done; --dry-run shows the plan. Details in docs/install.md.

06 / WHERE IT STANDS

An experiment, tested honestly.

Linux (IBus)Verified with real typing in containers: GTK, Qt, and GNOME Terminal on X11 (40 scenarios), GNOME on Wayland (12). KDE is not yet tested.
Windows (PIME/TSF)Verified on Windows 11 ARM64: Notepad, Edge, Windows Terminal, and the classic console; setup end to end. x64 hardware untested.
macOS (IMK)Verified with real typing on macOS 26 in a VM (9 scenarios). The app is not notarized yet.
